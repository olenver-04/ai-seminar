# Создание наглядных учебных материалов с помощью ИИ

Сайт для семинара: показываем учебные презентации (HTML-слайды и PDF),
аудитория вслепую голосует, какой ИИ их сделал — **ChatGPT**, **NotebookLM** или **Claude**,
затем ведущий раскрывает ответ и смотрит статистику.

Сайт статический (HTML + CSS + JS), без сборки — работает на GitHub Pages.

## Структура

```
index.html          — страница
css/style.css       — оформление
js/data.js          — ВСЕ НАСТРОЙКИ: заголовок, список работ, правильные ответы
js/app.js           — логика (менять не нужно)
presentations/      — сюда кладутся файлы презентаций
```

## Как добавить презентации

1. Положите файлы в `presentations/` с **нейтральными именами**: `01.pdf`, `02.html`, `03.pdf`.
   Не называйте их `chatgpt.pdf` — имя файла видно в просмотрщике и выдаст ответ.
2. Откройте `js/data.js` и для каждой работы укажите `format`, `file` и правильный ответ `ai`.
3. Поля `prompt` и `notes` (необязательно) показываются аудитории после раскрытия ответа.

> Совет: проверьте свойства PDF (Файл → Сведения): поле «Автор»/«Приложение»
> иногда содержит название сервиса. Очистите его, чтобы опрос был честным.

## Публикация на GitHub Pages

1. Создайте репозиторий на github.com (например, `ai-seminar`), публичный.
2. Загрузите все файлы этой папки (кнопка **Add file → Upload files** или через git):

   ```powershell
   git init
   git add .
   git commit -m "Сайт семинара"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/ai-seminar.git
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/ai-seminar/`.

Ограничение GitHub: один файл не больше **100 МБ** (через веб-загрузку — 25 МБ).

## Как проводить опрос на семинаре

- Откройте работу → смотрите → нажимайте кнопки ChatGPT / NotebookLM / Claude,
  считая поднятые руки (или клавиши **1 2 3**, **Shift+цифра** — убрать голос).
- **R** — раскрыть ответ, **F** — полный экран, **← →** — следующая работа, **Esc** — закрыть.
- Раздел «Итоги» — таблица голосов, процент угадавших и «узнаваемость» каждого ИИ.
  Кнопка «Скачать CSV» сохраняет результаты (открывается в Excel).
- Голоса хранятся в браузере компьютера ведущего. «Сбросить» — начать заново для новой группы.
- Голоса с телефонов складываются с ручными (см. раздел ниже).

## Локальный просмотр

Для проверки на своём компьютере:

```powershell
python -m http.server 8000
```

и откройте http://localhost:8000.

## Голосование с телефонов (QR-код)

Участники один раз сканируют QR-код. Телефон сам показывает ту работу, которую ведущий открыл
на экране, и после раскрытия ответа сообщает «угадал / не угадал». Голоса сразу появляются
на экране ведущего. Для этого нужна бесплатная база Firebase (Google), настройка ~5 минут:

1. Зайдите на https://console.firebase.google.com под своим Google-аккаунтом →
   **Create a project** (Google Analytics можно выключить).
2. Слева **Build → Realtime Database → Create Database** → регион любой →
   **Start in locked mode**.
3. Вкладка **Rules**: вставьте содержимое файла `firebase-rules.json` из этого репозитория → **Publish**.
4. Шестерёнка → **Project settings → General → Your apps → значок `</>` (Web)** →
   любое имя → **Register app**. Появится блок `firebaseConfig`.
5. Скопируйте из него `apiKey`, `authDomain`, `databaseURL`, `projectId`, `appId`
   в блок `firebase` в `js/data.js`. (Если `databaseURL` нет — возьмите адрес со страницы
   Realtime Database, вида `https://...firebasedatabase.app`.)

Эти ключи не секретные — их можно хранить в публичном репозитории, доступ ограничивают правила из шага 3.

**Режим ведущего.** Любой компьютер (с мышью или тачпадом), на котором открыт сайт, управляет
телефонами: открыл работу — телефоны переключились, нажал R — показали ответ. Телефоны и планшеты
ничего не переключают. Если нужно отключить управление в каком-то браузере, откройте сайт с `?host=off`
в конце адреса (включить обратно — `?host`).

**Разминка.** В начале семинара нажмите **🙋 Начать разминку** (клавиша **W**): на экране QR-код
и живые диаграммы, на телефонах — 2 вопроса об опыте с ИИ (анонимно). Закройте окно (**Esc**) —
телефоны перейдут в ожидание первой работы. Вопросы меняются в `warmup` в `js/data.js`.

**Оценки и рейтинг.** При первом входе телефон спрашивает имя. Пока ответ не раскрыт, участник
угадывает ИИ и ставит 1–5 звёзд по критериям (наглядность, точность, дизайн, «взял бы на урок») —
вслепую, чтобы название ИИ не влияло на оценку. Критерии меняются в `criteria` в `js/data.js`.
В разделе «Итоги» — таблица оценок по работам и рейтинг «кто лучше всех узнаёт ИИ»;
кнопка **🏆 Итоги на экран** (клавиша **T**) показывает финал крупно для проектора.

**На семинаре:** кнопка **📱 QR** (или клавиша **Q**) показывает QR-код крупно.
Для новой группы нажмите «Сбросить» или поменяйте `session` в `js/data.js`.

## Streamlit (необязательно)

`app.py` — обёртка для Streamlit Community Cloud: показывает сайт с GitHub Pages внутри Streamlit.
При деплое укажите **Main file path: `app.py`** и любой свободный адрес приложения.
Полноэкранный режим лучше работает по прямой ссылке на GitHub Pages.
